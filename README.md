# Jogo da Velha

Desenvolver o aplicativo Jogo da Velha usando flutter, que consiste em uma única tela com um campo de entrada de dados (TextField) para inserir o apelido do jogador, dois Radio para escolher o tipo do tabuleiro (3x3 ou 4x4), dois Radio para escolher X ou O e botão para iniciar o jogo.  Ao iniciar o jogo, o app deve mostrar o tabuleiro escolhido com o nome do jogador que deve fazer a jogada e um botão de Novo para criar um novo jogo.

Durante as jogadas, deve-se informar o nome do jogador da jogada (usuário ou máquina) e ao final deve-ser informar quem venceu ou se deu empate.
A construção do layout do app é livre.

Deve-se entregar o arquivo compactado contendo o projeto flutter com arquivos indicados a seguir e um print da tela rodando ele com algum simulador  (android, web ou desktop).

Arquivos na pasta do projeto flutter:
- Pasta lib;
- Pastas com images;
- Arquivo pubspec.yaml.
